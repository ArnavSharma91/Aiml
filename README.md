# 💪 Fitness Chatbot (Streamlit)

A simple **Fitness Chatbot** built using Python and Streamlit that helps users with basic fitness advice like workouts, diet tips, weight loss, and muscle gain.

---

## 🚀 Features

* 💬 Interactive chatbot UI
* 🏋️ Workout suggestions
* 🥗 Diet recommendations
* ⚖️ Weight loss guidance
* 💪 Muscle gain tips
* 🧠 Simple rule-based AI responses

---

## 🛠️ Tech Stack

* Python
* Streamlit

---

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/fitness-chatbot.git
cd fitness-chatbot
```

### 2. Install dependencies

```bash
pip install streamlit
```

---

## ▶️ Run the App

```bash
streamlit run fitness_chatbot.py
```

## 💡 How It Works

The chatbot uses simple keyword-based logic:

* Detects words like "diet", "workout", "weight loss"
* Responds with predefined fitness advice
